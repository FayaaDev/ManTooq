# تثبيت منطوق على Windows

إصدار Windows مخصص لمعالجات x64. حمّل ملف التثبيت `منطوق_0.1.0_x64-setup.exe` وشغّله، ثم افتح «منطوق» من قائمة Start. أدخل مفتاح ElevenLabs API من زر «مفتاح API». تحتاج إلى اتصال بالإنترنت لاستخدام ElevenLabs، لكنك لا تحتاج إلى تثبيت Python أو `uv`.

قد يعرض Windows SmartScreen تحذيرًا لأن التطبيق غير موقّع. لا تثبّت إلا ملفًا من مصدر موثوق. يحفظ التطبيق معرّف الصوت والبذور والتسجيلات في بيانات التطبيق المحلية، وتبقى بعد إغلاق التطبيق وإعادة تشغيله. لا يحفظ مفتاح API الذي تدخله في الواجهة.

## بناء نسخة محلية

على جهاز Windows x64، ثبّت Rust وNode.js و`uv` وMicrosoft C++ Build Tools، ثم شغّل PowerShell من مجلد المشروع:

```powershell
uv sync
.\scripts\build-windows.ps1
uv run python -m unittest -v
```

ستجد ملف التثبيت في `src-tauri\target\release\bundle\nsis\`. تبني العملية نسخة Python وStreamlit داخل التطبيق؛ لا تضمّن `.env` أو التسجيلات المحلية. جرّب تثبيت الملف على جهاز Windows، ثم أدخل المفتاح وارفع عينة وولّد صوتًا وحمّله وتحقق من بقاء التسجيلات بعد إعادة تشغيل التطبيق.

لا يمكن بناء ملف Windows من macOS؛ نفّذ البناء والتحقق على Windows. تتطلب مشاركة الملف خارج بيئة الاختبار توقيع التطبيق لتفادي تحذير SmartScreen.
