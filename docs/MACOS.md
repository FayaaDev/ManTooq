# تثبيت منطوق على macOS

حمّل ملف `منطوق_0.1.0_aarch64.dmg`، وافتحه، ثم اسحب «منطوق» إلى مجلد التطبيقات. شغّل التطبيق وأدخل مفتاح ElevenLabs API من زر «مفتاح API». تحتاج إلى اتصال بالإنترنت لاستخدام ElevenLabs، لكنك لا تحتاج إلى تثبيت Python أو `uv`. هذا الإصدار مخصص لأجهزة Mac بمعالج Apple Silicon.

يحفظ التطبيق معرّف الصوت والبذور والتسجيلات في `~/Library/Application Support/com.mantooq.desktop/`، وتبقى بعد إغلاق التطبيق وإعادة تشغيله. لا يحفظ مفتاح API الذي تدخله في الواجهة؛ أدخله مجددًا عند تشغيل التطبيق. يمكنك بدلًا من ذلك ضبط `ELEVENLABS_API_KEY` في بيئة تشغيل التطبيق. ملف `.env` في مجلد المشروع مخصص للتشغيل من المصدر ولا يُضمّن في التطبيق.

## بناء نسخة محلية

على جهاز Mac بمعالج Apple Silicon، ثبّت Rust و`uv` وNode.js وأدوات Xcode، ثم شغّل:

```sh
uv sync
sh scripts/build-macos.sh
uv run python -m unittest -v
```

ستجد التطبيق في `src-tauri/target/release/bundle/macos/`، وملف التثبيت في `src-tauri/target/release/bundle/dmg/`. تجمع عملية البناء نسخة Python وStreamlit داخل التطبيق؛ لا تضمّن `.env` أو التسجيلات المحلية. للتحقق من التثبيت، افتح ملف DMG وانسخ التطبيق إلى مجلد آخر ثم شغّله، وجرّب إدخال المفتاح ورفع عينة وتشغيل الصوت وتحميله ومراجعة التسجيلات بعد إعادة التشغيل. تتطلب مشاركة الملف خارج جهاز البناء توقيع التطبيق وتوثيقه لدى Apple قبل النشر.

للتطوير أو استخدام سطر الأوامر من المصدر، راجع [دليل البدء](README.md).
